# Лабораторная работа 1: Интернет магазин

Сайт представляет несколько коллекций женской и детской одежды и объединяет презентационную часть бренда с полноценным каталогом товаров. Пользователь может просматривать коллекции, фильтровать товары, переходить между страницами каталога, добавлять модели в корзину, изменять количество товаров и оформлять заказ.

## О проекте

Создан сайт дизайнерского бренда одежды с возможностью добавлять товары в корзину и оформлять заказы.

На странице представлены:

- логотип дизайнера;

- главный экран с именем дизайнера и кратким описанием;

- три коллекции одежды;

- каталог товаров;

- информация о дизайнере;

- контактные данные.

В каталоге представлены 29 моделей одежды из 3 коллекций.

### Коллекции

«Цветы империи» - Коллекция детской одежды, вдохновленная эпохой ампира.

«54/42» - Коллекция женской одежды, посвященная Сибири и будущему.

«Весенний сон» - Коллекция женской одежды, вдохновленная русским народным костюмом.

## Каталог

Каталог содержит карточки товаров с фотографией, названием, стоимостью и возможностью добавить товар в корзину.

Товары хранятся в виде структурированных объектов JavaScript. Для каждого товара задаются основные характеристики:

- уникальный идентификатор;

- название;

- цена;

- изображение;

- коллекция;

- тип одежды;

- категория покупателей.

Карточки товаров формируются динамически с помощью JavaScript. Это позволяет отделить данные о товарах от HTML-разметки страницы и добавлять или изменять модели без ручного создания каждой карточки.

## Фильтрация товаров

В каталоге реализована фильтрация по нескольким параметрам: коллекции (все, "Цветы империи", "54/42" или "Весенний сон"), категория одежды (все, блузы, брюки, юбки, платья и т.д.) и "Для кого" (все, женщины, девочки).

Фильтры можно комбинировать, панель фильтров можно свернуть. При наличии активных фильтров их количество отображается непосредственно на кнопке «Фильтры».

## Пагинация

Для удобства просмотра каталог разделен на страницы, на одной странице отображается до 8 товаров. Пагинация автоматически учитывает примененные фильтры. Если после фильтрации количество товаров изменилось, количество страниц также пересчитывается.


## Корзина

На сайте реализована интерактивная корзина. Пользователь может добавить товар в корзину,  увеличить или уменьшить количество выбранного товара, посмотреть итоговую стоимость заказа. Итоговая стоимость автоматически пересчитывается при каждом изменении количества товаров. Состояние корзины сохраняется в `localStorage`. Поэтому после обновления страницы ранее добавленные товары не исчезают.

## Оформление заказа

Оформление заказа происходит непосредственно в интерфейсе корзины. Форма заказа содержит следующие поля имя, фамилия, адрес доставки и номер телефона. Для формы используется стандартная HTML-валидация. Дополнительно реализована проверка формата номера телефона и маска ввода номера.

## Адаптивный интерфейс

Сайт адаптирован для различных размеров экрана.

Поддерживаются:

- компьютеры, ноутюукти

- планшеты

- мобильные устройства

Размеры элементов, сетка каталога, расположение навигации, фильтров и других блоков изменяются в зависимости от ширины экрана.

## Технологии

Проект реализован с использованием HTML5, CSS3 и JavaScript без сторонних фреймворков. Для хранения данных корзины используется LocalStorage, а для адаптивной верстки — Flexbox и CSS Grid.
